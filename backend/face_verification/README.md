# Face Verification Module – SIH26188

## Purpose

This module verifies whether the face extracted from an identity document matches the face captured from the user.

The module also performs image-based anti-spoofing/liveness checking on the selfie image.

---

## Module Flow

User Identity Document
        ↓
Document/OCR Module
        ↓
Face extracted from document
        ↓
User Live Camera / Selfie
        ↓
Face Verification Module
        ↓
Liveness / Anti-Spoofing
        ↓
Face Matching
        ↓
Verified / Not Verified

---

## Requirements

- Python 3.11 recommended
- DeepFace 0.0.100
- TensorFlow 2.21.0
- TF-Keras 2.21.0
- OpenCV 4.10.0.84
- PyTorch 2.14.0

---

## Installation

Create a virtual environment:

python -m venv venv

Activate it on Windows:

venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

---

## Usage

Import the verification function:

from face_module import verify_faces

Call the function with the two image paths:

result = verify_faces(
    "path/to/document_face.jpg",
    "path/to/live_face.jpg"
)

print(result)

---

## Input

### 1. Document Face Image

Path of the face image extracted from the user's identity document.

Example:

document_face.jpg

### 2. Live/Selfie Image

Path of the user's image captured through the camera.

Example:

live_face.jpg

The module does NOT use hardcoded test images.

The parent application should provide the actual user image paths at runtime.

---

## Output

Example:

{
    "status": "success",
    "data": {
        "verified": true,
        "similarity_score": 0.5231,
        "document_face_count": 1,
        "selfie_face_count": 1,
        "liveness_checked": true,
        "is_real": true,
        "anti_spoof_score": 0.9888
    },
    "errors": []
}

---

## Output Fields

### verified

true  → Document face and live/selfie face matched

false → Faces did not match

### similarity_score

Face matching score generated by the verification process.

This score should NOT be interpreted as a probability of identity.

### document_face_count

Number of faces detected in the document image.

### selfie_face_count

Number of faces detected in the selfie/live image.

### liveness_checked

Indicates whether the anti-spoofing check was performed.

### is_real

Result returned by the anti-spoofing model.

### anti_spoof_score

Score returned by the anti-spoofing model.

### errors

Contains error messages if verification fails.

## Integration with Main SIH Project

The main application should provide:

Document/OCR Module
        ↓
Document Face Image
        +
Camera Module
        ↓
Live Face Image
        ↓
verify_faces(document_face_path, live_face_path)
        ↓
Verification Result

Example:

result = verify_faces(
    document_face_path,
    live_face_path
)

if result["data"]["verified"]:
    print("Face Verified")
else:
    print("Face Verification Failed")

---

## Important Notes

- Test images used during development are not required for production.
- test_images should not be included in the production handoff.
- venv and __pycache__ should not be included in the handoff.
- The module accepts dynamic image paths supplied by the main application.
- The anti-spoofing check is image-based and should not be described as a guaranteed interactive camera liveness system.
